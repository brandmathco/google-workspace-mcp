Google Workspace MCP

Setup Wizard

Connect Gmail, Calendar, and Tasks to Cursor in a few guided steps. No coding required — we’ll tell you exactly what to copy from Google.

Install on this computer

We need Node.js 20+ (free). If the check below fails, install it from nodejs.org (click the big green LTS button), then re-open this wizard.

            Click below to open Google sign-in. Approve access for Gmail, Calendar, and Tasks.

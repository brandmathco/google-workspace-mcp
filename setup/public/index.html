What is Cursor?

Cursor is an AI code editor (like VS Code, but with a built-in AI chat). This MCP server lets that AI actually use your Gmail, Google Calendar, Google Tasks, and (optionally) spend-safe Google Ads — search mail, draft replies, create events, and draft paused ads.

  • You chat in plain English inside Cursor
  • Cursor calls tools from this app (securely, with your Google login)
  • You stay in control — review drafts before sending mail or enabling ad spend

Install Cursor on this computer first if you haven’t. You can finish the rest of this wizard, then come back to Cursor at the end.

Get this computer ready

The desktop installer already includes Node.js. If you used GitHub Releases, you’re set. Developers cloning the repo may need a one-time install below.
